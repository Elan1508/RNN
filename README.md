# RNN
A deep learning project using Recurrent Neural Networks (RNNs) to classify pizza customer reviews into Negative, Neutral, and Positive sentiments. Compares SimpleRNN, LSTM, GRU, and BiGRU architectures with text preprocessing and data augmentation. The optimised BiGRU achieves 91.53% test accuracy and a 0.9026 Macro F1-score.
